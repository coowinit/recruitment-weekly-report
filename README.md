# 招聘工作周报管理工具

**v1.1.0** · 一个纯前端、无需数据库的招聘周报 HTML 原型。示例内容均为虚构的通用部门、岗位和渠道，没有任何真实企业名称或个人招聘数据。

**当前仓库：周报复盘阶段。** 用于汇总每周招聘目标、面试与入职数据、下周计划和关键事项。

> **使用说明：** 三个工具均可独立使用，目前没有账户体系、共享数据库或自动数据同步。各项目的 JSON 备份格式不保证互相兼容；需要跨项目汇总时，请先核对统计口径，不要直接将一个项目的 JSON 导入另一个项目。

## 使用方法

1. 解压后双击 `index.html`，在现代浏览器中打开。
2. 修改报告人、部门、年月、周次；编辑岗位数据、招聘渠道、过程跟进与关键事项。
3. 点击“＋ 新增岗位 / 渠道 / 事项”以添加更多记录。
4. 修改后会自动保存到**当前浏览器的 localStorage**。请定期点击“导出 JSON”备份。
5. 后续使用“导入 JSON”可恢复数据。点击“打印 / PDF”即可使用浏览器打印或另存为 PDF。

> **重要：** 自动保存不是云同步，也不能替代 JSON 备份。更换浏览器、清理浏览器数据或使用隐私模式可能导致数据丢失；`file://` 下的 localStorage 支持情况因浏览器而异。不需要网络服务，也不会主动上传数据。

## 功能

- 招聘进度：本周目标、面试量、入职数、下周计划、月度目标及累计入职
- 自动汇总：周/月完成率、渠道转化率；分母为零显示 `—`
- 渠道管理：自定义招聘渠道与沟通/有效量
- 招聘过程：优化动作、面试、Offer / 谈薪、入职跟进
- 关键事项：项目、状态、目标、进度、异常与风险
- PC 端使用完整表格，手机端将岗位与渠道转换为可编辑的分组卡片
- 关键事项支持折叠展开：手机端新加载的事项默认折叠，点击“展开”后编辑
- 手机端顶部操作区和年月周次采用紧凑布局；JSON 文件选择框只在点击导入时打开
- 响应式布局、打印样式、JSON 导入导出、浏览器本地自动保存

## 数据口径

- 周完成率 = 本周实际入职 ÷ 本周目标 × 100%。
- 月完成率 = 手工录入的本月累计入职 ÷ 本月招聘目标 × 100%。
- 渠道转化率 = 有效/通过量 ÷ 沟通/推荐量 × 100%。
- 目标为零时显示 `—`，而非 Excel 的除零错误。
- 周面试量和周入职数是独立指标，不假设入职人员在本周面试。
- “第 N 周”只是月内的文字标识，不自动计算自然周的起止日期。
- 月度数据需手工录入；不会从历史周报自动叠加。

## 注意事项

- 本项目**不是** ATS 候选人管理系统，不提供用户登录、权限、云同步及数据库服务。
- 涉及候选人姓名、薪酬等敏感资料时，请在受控设备上使用，并谨慎分享 JSON 和 PDF。
- 不同渠道的“有效”定义不同，数据对比应先统一统计口径。
- `data/demo.json` 只是示例备份；点击“新建周报”即可开始空白记录。
